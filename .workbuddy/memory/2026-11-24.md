## 修复：start.bat 双击闪退（重要经验）

- 根因：.bat 若以 **UTF-8 无 BOM + LF** 保存，中文 Windows 的 cmd 按 cp936 读取 → 中文乱码被当成命令执行、`if (...)` 括号块边界解析错位，脚本提前结束，窗口一闪而过。与端口、Node 安装无关。
- 修复：start.bat 改为 **GBK(cp936) + CRLF + 无 BOM**，正文全部用 `if ... goto label` 单行形式，不用含中文的多行括号块；去掉对 `chcp 65001` 的依赖。
- 增加健壮性：`where node` 检测、5178 端口占用检测（已在运行则只开浏览器）、安装/构建失败与运行时异常均 `pause`；`server/index.mjs` 增加 `server.on('error')` 处理 EADDRINUSE（退出码 1，不抛堆栈）。
- 测试批处理时务必 `< /dev/null` 或后台运行，否则会卡在 `pause`（当时两个 cmd 进程因此挂死）。
- 验收：QA 6/6 通过（编码字节、静态审查、正常启动 health 200、端口占用分支、数据 5 条完整、服务端兜底）。
- `start.sh` 不受影响（bash + UTF-8）。


## 新增：定时提醒 + 今日焦点窗 + 便签（桌面端）

- 用户先要方案评估，选了 **C 轻量模式**：Electron 仅托盘常驻（主进程+托盘），弹窗与焦点窗按需创建、用完销毁；源码运行不打包。
- 实测基线：本机 15.3GB 内存已用 73%，Edge 19 进程 1805MB；因此按「常驻内存」而非安装体积做决策。
- 依赖：`electron@45`（node_modules 约 360MB），仅本机安装。安装时须 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，且 npm 的 postinstall 未自动下载时需手动 `node node_modules/electron/install.js`。
- 架构：`server/app.mjs`（路由/静态/焦点聚合，可被网页与桌面复用）→ `desktop/main.mjs`（托盘、窗口、IPC）→ `scheduler.mjs`（20s 扫描、去重、静默 22:00-08:00、6h 补发上限）。
- 数据：新增 `data/notes.json`、`data/settings.json`；memo 增 `reminderAt / reminderFiredAt / snoozeUntil`，改 reminderAt 时 store 自动清 fired 与 snooze。
- 窗口：极简版 toast（420x198，透明圆角，置顶 screen-saver 级，14s 自动收起、悬停暂停，完成/延后/打开）；焦点窗 384x560 无边框自绘标题栏（-webkit-app-region: drag），位置存 settings.focusBounds。
- 关键坑：**`ELECTRON_RUN_AS_NODE=1`** 由父环境注入，会把 Electron 降级成普通 Node，报 "does not provide an export named 'BrowserWindow'"。解法：`desktop/launch.mjs` 删除该变量后 spawn electron；npm script `desktop` 走启动器。

## 修复：关窗即停 + 抽屉标题被压扁

- 关窗即停根因：desktop.bat 前台跑 node launcher，Electron 作为子进程附着同一控制台；关闭控制台时 Windows 向所有附着进程发 CTRL_CLOSE，父子一起被杀。
  修法：launcher 改 `detached: true + stdio: 文件描述符 + child.unref()`，启动后 900ms 退出；日志落 `data/desktop.log`（超 2MB 清空）。bat 加 `timeout /t 3` 后自动退出，窗口消失。另加 `desktop-debug.bat` 前台看日志。
  验证：bat 退出后 health 仍 200、3 个 electron 进程存活。
- 抽屉挤压根因：`.drawer-body` 是 flex column，子项默认 `flex-shrink:1`，高度不足时标题 textarea 被压到 18px（rows=2 本应 ~68px），文字被拦腰截断。
  修法（用户选方案②）：新增 `.drawer-pin` 固定区（标题自适应 1–4 行 + 状态/优先级并排 segmented），body 子项 `flex:0 0 auto` 只滚动；备注不折叠（用户明确要求）。
  实测：标题 18px → 34px 不裁切；1080×642 下 body 可视 397px / 内容 629px（滚动）；1440×900 下 655px 完全放得下。
- 注意：`.drawer-pin .segmented button` 单独调小 padding/font，优先级用 P0-P3 短标签 + title 提示。
